# 뱅크샐러드 → 구글 캘린더 동기화

구글 드라이브 `가계부/inbox` 폴더에 뱅크샐러드 엑셀을 넣으면, 거래 내역을
하나씩 구글 캘린더 일정으로 만들어 줍니다. 처리가 끝난 파일은 `done` 폴더로
옮겨집니다.

서버에 SSH로 접속할 필요가 없습니다. Dockge 화면에서 compose 한 장만
붙여넣으면 깃허브에서 소스를 받아 알아서 빌드합니다.

## 동작 방식

```
뱅샐 앱 [파일로 받기]
      ↓  (메일로 엑셀 수신)
Gmail 앱 → [드라이브에 저장] → 가계부/inbox
      ↓  (컨테이너가 5분마다 확인)
zip 해제 → 엑셀 암호 해제 → 파싱 → 날짜별 집계 → 캘린더 등록
      ↓
가계부/done 으로 파일 이동
```

## 설정값

| 변수 | 기본값 | 설명 |
|---|---|---|
| `EXCEL_PASSWORD` | — | 뱅샐 엑셀 비밀번호 (필수) |
| `SERVICE_ACCOUNT_JSON_B64` | — | 서비스 계정 키 JSON의 base64 (필수) |
| `CALENDAR_EXPENSE` | — | 지출 캘린더 ID |
| `CALENDAR_INCOME` | — | 수입 캘린더 ID |
| `DRY_RUN` | `false` | `true` 면 실제 등록 없이 로그만 |
| `MAX_AGE_DAYS` | `0` | 이보다 오래된 거래 무시. `0` 이면 1년치 전부 |
| `POLL_INTERVAL_SEC` | `300` | inbox 확인 주기(초) |
| `INCLUDE_TRANSFERS` | `false` | 계좌간 이체도 등록할지 |
| `MIN_AMOUNT` | `1` | 이 금액 미만 제외 |
| `PURGE_ONCE` | `false` | `true` 면 시작할 때 기존 일정을 지우고 시작 |
| `PURGE_ALL` | `false` | `PURGE_ONCE` 시, 앱이 안 만든 일정까지 지울지 |
| `SERVICE_ACCOUNT_FILE` | — | base64 대신 파일 경로를 쓸 경우에만 |

## 평소 사용법

1. 뱅크샐러드 앱 → **[가계부]** → 우측 상단 톱니바퀴 → **[파일로 받기]**
2. 이메일 주소와 비밀번호 입력 (비밀번호는 `EXCEL_PASSWORD` 와 동일하게)
3. 메일이 오면 Gmail 앱에서 첨부 **zip 파일**의 드라이브 아이콘 → `가계부/inbox` 선택
   (압축을 풀 필요 없습니다. zip 그대로 넣으시면 됩니다)
4. 5분 안에 캘린더에 반영됩니다

## 일정 형태

하루에 종일 일정이 최대 2개 생깁니다. 거래가 없는 쪽은 만들지 않습니다.

```
💳 지출 267,160원 (4건)     ← 가계부-지출
💰 수입 6,142,190원 (1건)   ← 가계부-수입
```

일정을 열면 설명란에 시간순 상세 내역과 분류별 합계가 들어 있습니다.

## 중복 걱정 없음

뱅크샐러드는 항상 최근 1년치를 통째로 내보냅니다. 이 앱은 `날짜+지출/수입`
을 해시로 만들어 캘린더 이벤트 ID로 쓰기 때문에, 같은 zip을 여러 번 올려도
일정이 늘어나지 않습니다. 그날 거래가 추가된 경우에만 기존 일정의 내용이
갱신됩니다.

## 소스를 고친 뒤 반영하기

깃허브에서 파일을 수정하고 커밋한 다음, Dockge에서 해당 스택의
**Deploy** 를 다시 누르면 최신 코드로 새로 빌드됩니다.

## 문제가 생기면

Dockge의 로그 화면에서 확인하실 수 있습니다.

**`'가계부' 폴더를 찾을 수 없습니다`**
드라이브에서 `가계부` 폴더를 서비스 계정 이메일에 **편집자** 권한으로
공유했는지 확인해 주세요.

**`등록 실패 (403)`**
캘린더 공유 권한이 `일정 보기` 로 되어 있을 때 납니다. 캘린더 설정에서
**변경 및 공유 관리 권한** 으로 바꿔 주세요.

**`SERVICE_ACCOUNT_JSON_B64 가 올바른 base64가 아닙니다`**
복사 과정에서 줄바꿈이나 따옴표가 섞였을 가능성이 큽니다. 한 줄이어야 합니다.

**`zip 비밀번호가 틀렸거나 EXCEL_PASSWORD가 비어 있습니다`**
compose의 비밀번호가 비었거나, 뱅샐에서 내보낼 때 쓴 비밀번호와 다릅니다.

**`zip 안에 엑셀 파일이 없습니다`**
로그에 zip 내용물 목록이 함께 찍힙니다. 확장자가 `.xlsx`/`.xls` 가 아니면
`app/parser.py` 의 `SHEET_EXTS` 에 추가해 주세요.

**`헤더 행(날짜·금액)을 찾지 못했습니다`**
뱅크샐러드가 엑셀 양식을 바꿨을 가능성이 있습니다. 파일은 inbox에 그대로
남으니 데이터 유실은 없습니다. `app/parser.py` 의 `COLUMN_ALIASES` 에 새
컬럼명을 추가하면 됩니다.

## 일정을 싹 지우고 새로 만들기

일정 형식을 바꾼 뒤 기존 일정을 정리할 때 씁니다. 캘린더를 삭제할 필요가
없으므로 공유 설정과 캘린더 ID가 그대로 유지됩니다.

1. compose에서 `PURGE_ONCE: "true"` 로 변경
2. Dockge에서 Restart
3. 로그에 `정리 완료: 총 N건` 이 뜨는지 확인
4. **`PURGE_ONCE` 를 다시 `"false"` 로 되돌리고 Restart**

3번 직후 `done` 폴더의 파일이 자동으로 `inbox` 로 되돌아가므로, 정리와
재생성이 한 번에 끝납니다. 4번을 빼먹으면 재시작할 때마다 일정이 지워지고
다시 만들어집니다.

기본값은 이 앱이 만든 일정(`source=banksalad` 표시가 붙은 것)만 지웁니다.
직접 손으로 넣은 일정이 섞여 있어도 안전합니다. 정말 전부 비우시려면
`PURGE_ALL: "true"` 를 함께 켜세요.

## 되돌리기

캘린더에 잘못 들어간 경우, 구글 캘린더에서 `가계부-지출` / `가계부-수입`
캘린더를 삭제하고 다시 만들면 전부 지워집니다. 다른 일정에는 영향이 없습니다.
